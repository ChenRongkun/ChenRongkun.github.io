<div class="about">
  <h1>About Me</h1>
  <p>This is my personal blog built with Jekyll.</p>
  
  <h2>Step 1: Installation</h2>
  <p>Jekyll requires Ruby, Gem, and Bundler. Follow the official installation guide.</p>
  
  <h2>Step 2: Create a New Post</h2>
  <p>Posts are stored in the <code>_posts</code> directory. Create a new file with the format <code>YYYY-MM-DD-title.md</code>.</p>
  
  <h2>Step 3: Add Images</h2>
  <p>Images go in the <code>assets/images/</code> folder. Reference them using relative paths.</p>
  
  <h2>Step 4: Publish</h2>
  <p>Commit your changes and push to GitHub. GitHub Pages will automatically build your site.</p>
